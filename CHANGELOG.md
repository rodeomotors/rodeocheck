# RodeoCheck changelog

## 2.0.0 — Finalized V2
- Redesigned app as a Rodeo Motors dealer acquisition workspace
- Added inventory stages, stock number and lane/run fields
- Added estimated retail and target gross settings
- Added auction price, fees, transport, recon and other-cost inputs
- Added automatic all-in cost, projected gross, gross margin, max-bid and MMR-spread calculations
- Added itemized recon planner with custom rows
- Added 16-point inspection checklist with Pass / Attention / Fail / Not checked states
- Added auction announcements and condition notes
- Added title/NMVTIS detail field
- Added exact-VIN auction-domain search helpers
- Added shareable vehicle summary
- Added searchable saved vehicle reports
- Added inventory CSV export
- Added dashboard portfolio economics
- Improved contract analyzer finance context
- Added full JSON backup and restore
- Added migration support for V1 local data
- Updated PWA cache strategy and install instructions
- Preserved explicit separation between public data, manual checks and paid/proprietary history sources
